# Datheon Python Programming Internship

Beginner Python projects completed for the internship tasks.

## Task 1: Hangman Game
A command-line word guessing game where the player guesses one letter at a time.

**File:** `hangman.py`

## Task 2: Stock Portfolio Performance Tracker
Calculates portfolio value and gain or loss based on the ticker, purchase price, and number of shares. Saves a summary to a CSV file. The tracker uses sample current prices; they are not live market prices.

**Files:** `portfolio.py`, `portfolio_summary.csv`

## Task 3: Automated File Organizer
Organizes files into folders such as Documents, Images, Videos, Archives, Code, or Other based on their extensions. It asks for confirmation before moving files.

**File:** `organizer.py`

## Task 4: Rule-Based Interactive Chatbot
Responds to questions about business hours, products, shipping, and returns using keyword rules. Type `bye`, `exit`, or `quit` to close the chatbot.

**File:** `chatbot.py`

## How to run

Install Python 3, open a terminal in the repository folder, and run the command for the project you want to try:

```bash
python hangman.py
python portfolio.py
python organizer.py
python chatbot.py
